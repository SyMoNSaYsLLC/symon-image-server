📖 What Is a Tensor?

A tensor is a generalisation of scalars, vectors, and matrices to any number of dimensions. Every weight, activation, and gradient in a neural network lives inside a tensor.

Rank Name Shape example ML use
0Scalar[]Learning rate
1Vector[512]Token embedding
2Matrix[4096, 4096]Attention Q/K/V weight
33-D Tensor[batch, seq, dim]Batch of token sequences
44-D Tensor[N, C, H, W]Image batch for vision models

Key Operations

  • Matmul (A @ B) — core of attention and feed-forward layers
  • Element-wise add/mul — residual connections, gating
  • Softmax — converts logits to attention weights or output probabilities
  • Reshape / Transpose — rearrange axes without copying data
  • Quantisation — pack weights into fewer bits (FP32 → Q4_K_M saves ~8×)

LoRA: Efficient Fine-Tuning

LoRA adds a low-rank decomposition to model weights instead of updating them all: 

W_adapted = W_base + alpha × (B @ A)
# A: [rank × d_in],  B: [d_out × rank],  rank ≪ d_in, d_out

Merge LoRA adapters using helpers/python/lora_merge.py: 

python helpers/python/lora_merge.py base.safetensors adapter.safetensors merged.safetensors
